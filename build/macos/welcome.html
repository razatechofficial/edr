Install EDR Agent

This package installs EDR Agent for all users of this Mac (per-machine). It registers a LaunchDaemon that starts the sensor at boot and a Login Item that opens the console at login.

Administrator authentication is required. After this installer finishes, open EDR Agent from Applications to enroll, grant Full Disk Access, and watch copy-progress on first launch.

Silent fleet: MDM can deploy this package with a PPPC profile (Full Disk Access) and skip the wizard.
